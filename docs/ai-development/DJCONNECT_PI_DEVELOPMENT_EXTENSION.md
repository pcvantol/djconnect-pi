# DJConnect Pi development extension

`djconnect-pi` owns the Raspberry Pi ambient client, its service/display runtime and Pi packaging source. DJConnect remains the product-authority for cross-component architecture and roadmap.

Use `docs/ARCHITECTURE.md`, `docs/BOOTSTRAP.md`, `TESTS.md`, `pyproject.toml`, `requirements.lock`, and the existing Pi validation/release workflows for local work. Existing Trusted Delivery evidence remains authoritative.
